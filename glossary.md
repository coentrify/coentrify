# Glossary

The words coentrify uses most.

- The People - who does what
- The System - what a project adopts
- The Work - how a piece of work moves
- Keeping It Right - how the system stays true

## The People

- [Director](how-it-works.md#the-director) - the human who directs a project
- Agent - the AI that does the work

## The System

- [Coentrify](origin.md) - to align a project with spec-driven development
- [Harness](standards/behavior/always-make-no-mistakes.md) - the standards, checks and tools an agent works within
- [Pillar](philosophy.md) - one of the four principles the system rests on
- [Standard](standards.md) - a rule, a convention or a template that a project adopts
- Module - the standards on one subject
- [Read First](standards/overview.md) - the standards an agent reads at the start of every session
- Check - code that refuses on its own when a rule is broken
- [Law](standards/gamedev/game-design-laws.md) - a short rule that holds unless there is a very good reason to break it
- Why - the goal or the principle behind a rule
- Part page - one part of a standard that grew past a page, titled with its parent's title before a colon

## The Work

- Layer - docs, specs, tests and code, each checked against the layer before
- [Spec](standards/docs/feature-spec-template.md) - the use cases of one feature, each with a stable id
- Use case - one scenario that a person runs by hand and a test implements
- [Proof](standards/tickets-workflow/the-done-part.md) - something the director opens or does to see that the work is done
- [Go](standards/behavior/a-go-before-work-elsewhere.md) - the director's yes for one named piece of work
- [Maybe](standards/behavior/a-maybe-is-a-trigger-to-investigate.md) - an idea the director is unsure of, which an agent looks into right away
- [Veto](standards/behavior/flag-every-addition-of-your-own.md) - the director undoing a choice that an agent made and listed
- [Phase](standards/behavior/project-lifecycle.md) - the stretch a project is in, which decides what matters now
- Gate - the one question that ends a phase

## Keeping It Right

- [The loop](how-it-works.md#the-loop) - a gap or a mistake becomes a standard or a check, so it happens once
- Gap - a difference between two layers, such as a spec case without a test
- [Gap analysis](standards/behavior/regular-layered-gap-analysis.md) - a walk along the layers, looking for gaps
- Drift - layers or rules that moved apart over time
- [Sweep](standards/behavior/sweeps-enumerate-into-tech-debt-first.md) - a pass over every instance of a pattern, to bring old work in line with a rule
- [Focus level](standards/docs/docs-are-hierarchical-explicit-and-short.md) - the level a page speaks at, such as a workspace, an application or a feature. Also called its altitude or its level of awareness
