# coentrify

`npx coentrify` points an agent at [coentrify](https://github.com/coentrify/coentrify): standards, checks and tools for spec-driven development with AI agents.

The package holds no standards and runs nothing but a print. It names the next step and links the latest release of the source. Its own version counts the package, never coentrify's.

- `npx coentrify` - set the project up
- `npx coentrify update` - bring the project up to date
- `npx coentrify explain` - say what coentrify is
