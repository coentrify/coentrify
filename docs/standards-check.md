# Standards Check

The worklist from a check of every standard in 0.0.6. The mechanical findings are fixed. A finding leaves the list once it is ruled and applied.

## Waiting For A Ruling

1. When a missing component is added and when the director is asked. UI Components First starts both cases from a component the design system does not have.
2. When the suites run. Gamedev Working Cadence runs them once at the end of a story, while Building A Ticket wants the touched suites green per ticket.
3. Release and Aftercare have no phase gate, while Game Phases says every phase ends at one.
4. Generate, Never Reuse bans every pack, while Own Icons lets a third party set bootstrap the start.
5. AFK Safe says nothing progresses while the player is away, and then lets currency grow.
6. ARC is called a pattern rather than a strict rule, inside a set of laws.
7. Work Tracking says debt never prescribes its implementation, while the Ticket Template gives debt a Solution section.
8. Stabilize Before Adding has the plan say so in its focus line, and the generated plan has no focus line.
9. Always Add Explicit Types: whether a function assigned to a binding that carries the full function type may leave its own parameters unannotated.
10. Game Phases: Development holds the rule that the agent names undecided content under Veto, under Pre-Alpha, while names are also chosen in later phases.
11. The plan template keeps an `## Overview` heading over its list, while the bugs and debt templates put theirs under the title with no heading.
12. Writing A Ticket names the conductor or a docs agent as the one who grooms a ticket.

## Bloat

- Agent Roles - about 900 words. Eight rules of the builder's brief have no home of their own: never amend a commit, measure a criterion once, the checks before each commit, run only what the change affects, a check that needs no browser is a unit test, grep the docs for content facts, no personal data in web requests, and muted browsers.
- Parallel Agents - about 620 words. Its Landing section repeats the refusals the Landing spec owns.
