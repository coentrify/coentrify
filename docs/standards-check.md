2. AFK Safe says nothing progresses while the player is away, and then lets currency grow.
3. ARC is called a pattern rather than a strict rule, inside a set of laws.
4. Work Tracking says debt never prescribes its implementation, while the Ticket Template gives debt a Solution section.
5. Stabilize Before Adding has the plan say so in its focus line, and the generated plan has no focus line.
6. Always Add Explicit Types: whether a function assigned to a binding that carries the full function type may leave its own parameters unannotated.
7. Game Phases: Development holds the rule that the agent names undecided content under Veto, under Pre-Alpha, while names are also chosen in later phases.
8. The plan template keeps an `## Overview` heading over its list, while the bugs and debt templates put theirs under the title with no heading.
9. Writing A Ticket names the conductor or a docs agent as the one who grooms a ticket.
