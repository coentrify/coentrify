# Plan

Version 0.2.3: the roadmap items an agent can do on its own.

- The advanced release workflow (active)
- Asset types
- The Node port
- The Proof page
- Call 0.2.3

## The Advanced Release Workflow

A standard for a product that is live: stories merge into a development branch, which is promoted to a release branch, accepted there and merged into main.

## Asset Types

Gamedev gets a list per asset type, with a template for characters, buildings, vehicles, outfits and the like.

## The Node Port

The update and unlink scripts run from the package, ported to Node.

## The Proof Page

The Proof page becomes a quick overview: one table with the rule, the trap, a summary and the data per model.
