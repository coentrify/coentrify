# Roadmap

The versions on the way to 1.0.

- 0.0.x - the standards move in and the first version is refined
- 0.1.0 - the director calls it ready for a user test
- 0.1.x - tweaks from a test run on a real project
- 0.2.x - a second project moves onto the package, one that already ran an earlier coentrify from memory
- 0.3.x - autonomy as an opt-in: the agent directs and the director is a stakeholder, piloted on games
- 1.0.0 - the director is happy with the whole

## Next

- Probe the standards again at every new model release, on new traps.
- Check each new game law against the psychology findings as the laws grow, so it ends with the findings it rests on or says it rests on none.
- Probe the bare word again once coentrify is indexed and linked from other sites, and simplify the first prompt when it passes.
- Record a video of the install, as proof that it works.
- Sweep every page once more for sanity, the way 0.0.8 did, after all that 0.2.x added.
- Standards to make a book or a movie from a game's wiki, as an extra output of the game.
- Pilot sessions on `autonomous` and `guided`, once 0.3.0 is released, with the template in [Pilots](pilots.md).
- Run `coentrify extract flavors` on the projects at work and on a few public games, once 0.3.0 is released, to grow the flavors.
- Dissect famous, typical games against the system: how each fits the layers, the laws and the patterns, so what the system misses comes to light.
