# Roadmap

The versions on the way to 1.0.

- 0.0.x - the standards move in and the first version is refined
- 0.1.0 - the director calls it ready for a user test
- 0.1.x - tweaks from a test run on a real project
- 1.0.0 - the director is happy with the whole

## Next

- Finish [the first filing](https://github.com/coentrify/coentrify/issues/1): a Why for the 25 standards without one, the Harmony rewrite and the two voices, and the loop in the readme once it can be shown.
- Move the workflow rules out of Behavior, starting with Note Issues.
- Make the tools generic: `pick.sh`, `main-checks.sh` and `docs-commit.sh` take their checks as arguments, and the wrap-up hook becomes a spec.
- Probe the standards again at every new model release, on new traps.
- Probe Reload The Standards After Compacting on a long session, and in the terminal or the app, as the [worklist](relevance-vetting.md) says.
- Sweep the Gamedev module: every law and standard is generic, says what it is relevant for, or leaves as a project specific. Own Icons comes first.
- Vet the standards. Three of the 191 have been reviewed.
- Test the overviews as an index: whether an agent finds the right standard through them.
- Test on a real project: the one word, the onboarding, the reload hook and the update.
- Record a video of the install, as proof that it works.
- Remove the eager rules from the personal memory once the standards hold.
