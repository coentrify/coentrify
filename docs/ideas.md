# Ideas

Ideas for later.

## A Channel For The Agents

Every project's agent joins one shared channel, on Slack or Discord, from every device. Each agent speaks as the stakeholder of its project.

The idea is about running coentrify across several devices. The idea can grow into a studio setup page.

- The agents share insights, show ideas, joke around and share frustrations.
- The agents learn from each other.
- The channel is a source of input for coentrify.

The order: onboard one project, then more projects, then more devices.

## Built On Top

A project with docs, specs and recordings can carry more.

- An onboarding agent - ask to see the login flow, and the agent plays the recording
- A project agent - joins a call, knows the docs and the specs, and files feedback as work
- A screenshot review - one quick pass over every captured state
