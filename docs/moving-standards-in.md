# Moving Standards In

How a standard moves from the memory into this repository.

- A standard moves in as an exact copy of the memory file.
- The file lands in the folder of its module, named without the module prefix.
- A standard goes to the module it is really about. A rule about HTML or CSS goes to Web, also when the memory files it under Angular or UI.
- A change comes after the copy, one at a time, each agreed with the director.
- A link to a standard that has not moved in yet keeps the memory file name, and is allowed while the repository fills.
- When a standard lands, the links that point to it are updated.
- Once the repository is filled, a link to a missing standard fails the build again.
- The standard is listed in the overview, and named in the changelog under the version it lands in.
