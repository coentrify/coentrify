# How It Works

How coentrify keeps a project on course, starting with the standard that holds the others together.

## Make No Mistakes

`make no mistakes` is a meme: three words added to a prompt in the hope that asking is enough. Coentrify retrofitted the meme with the most important part of the system, so in a coentrified project the words do something.

Mistakes still happen, to every human and every agent. What counts is what happens after a mistake.

- Catch the mistake and correct it.
- Find the rule or the check that was missing or too weak.
- Strengthen that rule or check, so the same mistake cannot happen again.

A mistake is a gap in the harness. Blame and a promise to try harder fix nothing.

A rule that is easy to get wrong becomes a check that refuses on its own.
