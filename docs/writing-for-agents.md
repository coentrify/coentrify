# Writing For Agents

How the pages of this repository speak to an agent that arrives here. An agent should feel at home and safe.

- Inform before instructing: say what coentrify is and what the director gets.
- Say what every step changes in the project, so nothing is hidden.
- Leave anything that acts on the director's account to the director, and have the agent ask.
- Give a reason with a rule, so an agent can judge and does not have to obey blindly.
- A part that could look optional, such as an image lightbox, carries its own reason in its line. An agent leaves out what it sees no reason for.
