# Attribution Check

A spec for a hook that refuses a commit message with attribution in it ([No Attribution](../../standards/commits/commits.md#no-attribution)).

## Where It Runs

- As the commit-msg hook, on every commit, an agent's or a person's.
- It reads the message file git hands it, and refuses with a message that names the line and the rule.

## What It Does

- It refuses a line that opens with a `Co-Authored-By:` trailer, a `Claude-Session:` line, or a "Generated with Claude Code" or "Generated by Claude Code" line, in any letter case.
- The linked form counts too, such as the name of the agent as a link.
- A line counts when the attribution opens it, after marks such as an emoji, a bullet or an underscore, so a sentence that names the phrase passes.
- It stops reading at git's scissors line, since the diff a verbose commit shows below it never reaches the message.

## The Check

- A plain conventional message passes.
- A `Co-Authored-By:` trailer refuses, in capitals and in lower case.
- A `Claude-Session:` line with its link refuses.
- A "Generated with Claude Code" line after a robot emoji refuses, and so does its linked form.
- A body sentence that names the phrase in its middle passes.
- A `Co-Authored-By:` line in the diff below the scissors line passes.
