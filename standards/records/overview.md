# Overview

The Records standards: the dated trails a project keeps.

- [Activity Log](activity-log.md) - a daily activity page: a short standup, what stands and what is next
- [Changelog Per Version](changelog-per-version.md) - a page per version, generated: the tickets that landed in it, each its id and link, in landing order. Nothing written by hand but the header. Without tickets, a line per landing through the append script. The DEV day counts the days with a commit
- [Healing Log](healing-log.md) - every change automatic healing made, one line each, until the director rules on it
- [Playtest Files](playtest-files.md) - a numbered file per playtest. Feedback units become tickets
- [Request Log](request-log.md) - log everything the director says before intake, shell-written time headings
- [User Test Files](user-test-files.md) - a numbered file per session with real users, in the shape of a playtest file
