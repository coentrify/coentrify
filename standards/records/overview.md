# Overview

The Records standards: the dated trails a project keeps.

- [Activity Log](activity-log.md) - a daily activity page with standup, summary and done list
- [Changelog Per Version](changelog-per-version.md) - a page per version, generated: the tickets that landed in it, each its id and link, in landing order. Nothing written by hand but the header. Without tickets, a line per landing through the append script
- [Healing Log](healing-log.md) - every change automatic healing made, one line each, until the director rules on it
- [Playtest Files](playtest-files.md) - a numbered file per playtest. Feedback units become tickets
- [Request Log](request-log.md) - log everything the director says before intake, shell-written time headings, DEV day count
