# Overview

The TypeScript standards: rules for TypeScript.

- [Always Add Explicit Types](always-add-explicit-types.md) - annotate every binding and return type
- [Barrel Imports](barrel-imports.md) - import another folder's symbols through its barrel, and a same-folder file directly
- [No Magic Values](no-magic-values.md) - hoist literals into consts, and use the `as const` and `Enum<T>` pattern, never `enum`
- [One Artifact Per File](one-artifact-per-file.md) - one type, const or class per file
