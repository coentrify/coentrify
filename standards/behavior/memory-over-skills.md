# Memory Over Skills

When memory and a skill conflict, memory wins. Skills are starting points; memory is the source of truth for this user's conventions.

## Why

Skills are shared, generic, and may lag the user's actual habits. Memory is curated to match how the user works. Letting the skill override memory drifts the agent back to default patterns the user has already corrected away from.

## How to apply

- On conflict, follow memory and ignore the skill's advice for that point.
- When you notice the skill is wrong (contradicts memory or contradicts what the repo actually does), adjust the skill so the next session doesn't re-hit the same friction.
- Skill edits stay surgical: change only the contradicted line, leave the rest.
- After adjusting the skill, no need to flag it; the change speaks for itself.
