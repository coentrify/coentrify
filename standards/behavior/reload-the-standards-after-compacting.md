# Reload The Standards After Compacting

After a compaction, read the Read First standards again.

## Why

When an agent's context is compacted, a summary takes the place of what the agent read. The standards go with it, and an agent that carries on works from memory of them.

## How to Apply

- Read again any other standard the work at hand needs.
- Where the agent supports hooks, let a hook reload the Read First standards, so no step depends on remembering.
