# Project Lifecycle

A project is in one phase at a time, and the phase decides what matters now.

## Why

The same work is right in one phase and wasted in another. A prototype needs speed, and a product in production needs care.

## How to Apply

- Name the phase the project is in.
- State the goal of the current phase, and keep the work on that goal.
- Weigh every piece of work against the goal of the current phase.
- File what does not serve the current phase for a later one.
- A game follows the [Game Phases](../gamedev/game-phases.md).
- A web product can go from a prototype to a skeleton, a design and production.
