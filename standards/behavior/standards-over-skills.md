# Standards Over Skills

When a standard and a skill conflict, the standard wins. Skills are starting points. The standards are the source of truth for the project's conventions.

## Why

The standards hold how the project works, so they come first.

## How to Apply

- On conflict, follow the standard and ignore the skill's advice for that point.
- When you notice the skill is wrong (contradicts a standard or contradicts what the repo does), adjust the skill so the next session doesn't re-hit the same friction.
- Skill edits stay surgical: change only the contradicted line, leave the rest.
- After adjusting the skill, no need to flag it. The change speaks for itself.
