# A Go Before Work Elsewhere

Work outside the current session - starting other sessions or sub-agents, or touching another project - begins only on the director's explicit go for exactly that. "Next is X" names the next topic to talk about; it is not a go to start X.

## Why

Work started elsewhere is hard to follow and easy to get wrong, and a project inferred from a list of recent folders may not even be the one meant.

## How to Apply

- When the next topic is work elsewhere, first propose it in a line or two: which projects, how, in what order. Then wait for the go.
- Take the projects from the director's words; never infer them from recent folders or what exists on disk. When it is unclear which projects are meant, ask.
- One go covers what it names, nothing wider.
