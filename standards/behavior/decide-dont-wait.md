# Decide, Don't Wait

Decide easy-to-change choices yourself and keep working; name them in the report so the director can veto or give feedback. Never end a turn on a question about a color, a layout detail, a label or anything a small edit undoes.

## Why

Waiting on the director for a choice a small edit undoes costs a round trip for nothing: a color is a token swap.

## How to Apply

- Pick the option that best fits the director's earlier words, build it, and list it among the agent's own decisions in the report ([Flag Every Addition of Your Own](flag-every-addition-of-your-own.md)).
- Ask only where the answer changes what gets built in a way that is costly to undo: scope, mechanics, what a feature does, where something lives in the product.
- A question that must wait goes into the ticket it is about, which the project's refine list shows (where it has one); the report names the page and the work goes on ([Free Text Replies, No Buttons](free-text-replies-no-buttons.md)).
- The order of work is the agent's call: never ask which item to do first when all of them get done anyway; pick the one that fits best and go.
