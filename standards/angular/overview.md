# Overview

The Angular standards: rules for Angular.

- [Angular Build Checks The Templates](angular-build-checks-the-templates.md) - tsc skips templates; ng build is the compile check
- [canMatch + Wildcard for Route Access](canmatch-wildcard-for-route-access.md) - canMatch guards plus a `**` wildcard for route access
- [Interface, Not Abstract Class, For Mock Swap](interface-not-abstract-class-for-mock-swap.md) - real and mock services share an interface, swapped via useClass
- [No `$any` in Templates](no-any-in-templates.md) - no casts or logic in templates
- [No Inline Templates](no-inline-templates.md) - templates in sibling .html files
- [One Component per Folder, Flat](one-component-per-folder-flat.md) - one component per folder, siblings flat
- [One Projected Node Per Control-Flow Block](one-projected-node-per-control-flow-block.md) - one projected node per @if for named slots; NG8011 is a failure
- [Prefer Content Projection over Props (Angular)](prefer-content-projection-over-props-angular.md) - ng-content slots over data props
- [Projected Content Is Never Styled by the Host](projected-content-is-never-styled-by-the-host.md) - host styles never reach projected content
- [Static Attribute, Not Literal Binding](static-attribute-not-literal-binding.md) - constant strings are plain attributes, not bindings
- [Track Timed Items by an Id](track-timed-items-by-an-id.md) - timed list items track by an id the item carries
- [UI Copy in Template](ui-copy-in-template.md) - UI copy lives in the template's matching branch
- [Use Modern Angular Template APIs](use-modern-angular-template-apis.md) - [class], [style] and @if/@for over the legacy directives
