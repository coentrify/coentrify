# Game Design Patterns

Named patterns a game can use, each with what it does and when it fits. A game uses a pattern where it fits. A law holds everywhere, unless there is a very good reason ([Game Design Laws](game-design-laws.md)).

## Why

A named pattern is reused on purpose and recognized when it comes up, so it never has to be invented again.

## No-Gear Level

A No-Gear level takes the player's gear away for a while: the tools, the money, the places, the network. The player plays the core loop again from nothing, in a limited place.

- It is an intermezzo, a disruption in the middle of the game, never the end game.
- The loop the player knows carries it, so nothing new has to be taught: the player proves the skill without the gear.
- The loss answers something the player did, such as getting caught, never a twist out of nothing ([Fair Surprise](game-design-laws-world.md#fair-surprise)).
- It ends with the gear coming back, which makes what was built feel earned a second time ([Earned Progress](game-design-laws-progress.md#earned-progress)).
- A game may open with one as well: an opening that shows a later setup, then takes it away.
