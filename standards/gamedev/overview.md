# Overview

The Gamedev standards: game development.

- [2D Visual Design](2d-visual-design.md) - drawn scenes keep one perspective: verticals vertical, edges to the vanishing point, repeats converging, patterns foreshortened. Checked with lines drawn over a capture
- [Asset List Template](asset-list-template.md) - a list per asset type in the docs: the blueprint first, then an entry per asset, with fields per type
- [Captures And Reels](captures-and-reels.md) - proof from scripted captures per item, never by hand, reels on demand, videos untracked in git
- [Devbox](devbox.md) - a one-key devbox on every scene, on the shared seeded scenarios
- [Game Design Laws](game-design-laws.md) - the generic game design laws as an index. A game's laws doc adopts, leaves out or overrides them by name
- [Game Design Laws: Companions](game-design-laws-companions.md) - the characters who stand with the player
- [Game Design Laws: Experience](game-design-laws-experience.md) - what the player lives moment to moment
- [Game Design Laws: Guidance](game-design-laws-guidance.md) - what the game hints and teaches
- [Game Design Laws: Own Style](game-design-laws-own-style.md) - what makes the game its own
- [Game Design Laws: Progress](game-design-laws-progress.md) - the shape of the whole game
- [Game Design Laws: Quality](game-design-laws-quality.md) - the bar everything in the game meets
- [Game Design Laws: Story](game-design-laws-story.md) - what the game says
- [Game Design Laws: UI](game-design-laws-ui.md) - the screen and the controls
- [Game Design Laws: World](game-design-laws-world.md) - the world the player moves through
- [Game Design Laws: Values](game-design-laws-values.md) - what a game does to the person playing it
- [Game Design Patterns](game-design-patterns.md) - named patterns a game uses where they fit, such as the No-Gear level and Ma
- [Game Flavors](game-flavors.md) - ready-made strategies per layer of a game, picked, rolled by code, or the game's own. No default taste
- [Game Flavors: Naming](game-flavors-naming.md) - how the characters are named
- [Game Phases](game-phases.md) - a game's phases in four stages, each phase but Post-Release ending at a phase gate, with the greybox, demos and outside playtests
- [Game Phases: Concept](game-phases-concept.md) - the divergent stage: Idea, Gathering, Outline and Prototype, loose inside and without tickets
- [Game Phases: Design](game-phases-design.md) - the convergent stage: Lore, World Building, Gameplay, First Playable and Game Design. A first playable is never a demo
- [Game Phases: Development](game-phases-development.md) - Pre-Alpha is functionally complete: every part present, rough allowed, undecided content on the agent's recommendation. Alpha polishes, Beta is for outsiders
- [Game Phases: Live](game-phases-live.md) - Release, Aftercare and Post-Release. An everlasting project, so Post-Release has no phase gate
- [Game Work Workflow](game-work-workflow.md) - the game layer on the work workflow: the user is the player, addressed as you, the game's own words, playtests feed intake, Lore and Game ticket types, the four stages in a line each
- [Gamedev Working Cadence](gamedev-working-cadence.md) - the game day loop, feedback on an open version is a cutoff, full pre-push hook before the tag, nothing new after a wind-down
- [Gate Check Questions](gate-check-questions.md) - a few questions per phase gate, each tied to a law, answered with reasoning. They prepare the director's call, and make it at `autonomous`
- [Incremental Pacing](incremental-pacing.md) - a pacing doc per level mirroring the configuration
- [Launch Strategy](launch-strategy.md) - how a game goes out: the quiet launch by default, the other choices, and what to weigh
- [Measure Sound, Never Guess](measure-sound-never-guess.md) - the level of a new sound is measured against a known sound, never guessed
- [Own Icons](own-icons.md) - own icon sprite, named by concept, with a wiki index page
- [Prototype Phase Template](prototype-phase-template.md) - the Prototype phase page: what it tries, the round, the loop mechanism and its balance, what it needs, the questions with the law each tests, and what comes out of it
- [Silent Runs](silent-runs.md) - an agent's runs of a game make no sound: muted Playwright captures for a walk, never the browser pane on a game with sound
- [Sprite Sheet Frames](sprite-sheet-frames.md) - read frame size and row order from the sheet's pixels
- [Wayfinding](wayfinding.md) - for a world the player finds the way in: paths, edges, districts, nodes and landmarks, strong and clear, after Kevin Lynch. A sketch-map test after a playtest checks it
