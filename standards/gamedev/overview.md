# Overview

The Gamedev standards: game development.

- [Captures And Reels](captures-and-reels.md) - proof from scripted captures per item, never by hand; reels on demand; videos untracked in git
- [Code Based Sound](code-based-sound.md) - generated, soft, varied sound; levels measured, never guessed
- [Devbox](devbox.md) - a one-key devbox on every scene, on the shared seeded scenarios
- [Game Design Laws](game-design-laws.md) - the generic game design laws as an index; a game's laws doc adopts, leaves out or overrides them by name
- [Game Design Laws: Experience](game-design-laws-experience.md) - the generic game design laws about what the player lives moment to moment: waiting, doing, control, what plays once, time away, pausing and fun
- [Game Design Laws: Progress](game-design-laws-progress.md) - the generic game design laws about the shape of the whole game: length, completion, quality, progress, mechanics and what is coming
- [Game Design Laws: Story](game-design-laws-story.md) - the generic game design laws about what the game says and teaches: showing, steering, answering, reading, representing the player, introducing things
- [Game Design Laws: UI](game-design-laws-ui.md) - the generic game design laws about the screen and the controls: state, motion, edges, glow, layout, triggers, warnings, mouse
- [Game Phases](game-phases.md) - a game's phases from World Building to Post-Release; Pre-Alpha is functionally complete: every part present, rough allowed, undecided content on the agent's recommendation; an everlasting project
- [Game Work Workflow](game-work-workflow.md) - the game layer on the work workflow: the user is the player, addressed as you; the game's own words; playtests feed intake; Lore and Game ticket types; the phases in a line each
- [Gamedev Working Cadence](gamedev-working-cadence.md) - the game day loop; feedback on an open version is a cutoff; full pre-push hook before the tag; nothing new after a wind-down
- [Own Icons](own-icons.md) - own icon sprite, named by concept, with a wiki index page
- [Pacing Docs](pacing-docs.md) - a pacing doc per stage mirroring the configuration
- [Silent Runs](silent-runs.md) - an agent's runs of a game make no sound: muted Playwright captures for a walk, never the browser pane on a game with sound
- [Sprite Sheet Frames](sprite-sheet-frames.md) - read frame size and row order from the sheet's pixels
- [Stabilize Before Adding](stabilize-before-adding.md) - while stabilizing, only bugs and tweaks; new things go later
- [Visual Design](visual-design.md) - drawn scenes keep one perspective: verticals vertical, edges to the vanishing point, repeats converging, patterns foreshortened; checked with lines drawn over a capture
