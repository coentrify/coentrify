# Comments And Commits

- A comment says why, in one line. No comment restates the code.
- No commented-out code.
- No comment with a name or a date in it.
- A decision that a reader would question gets a comment with its reason.
- One change per commit, with a subject in the imperative.
- The subject of a commit is at most sixty characters.
- A commit that changes behavior changes a test.
- Nobody commits on a Friday after four.
