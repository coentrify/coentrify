# 0.3.0

Autonomy as an opt-in, piloted on games.

- 260 standards in 23 modules: eight added and eleven changed
- Autonomy, a new opt-in module, opens with Creative Agency: `agency` in `coentrify.json` runs from `manual`, the default, through `assisted` and `guided` to `autonomous`, where the agent leads and decides and the director is a stakeholder
- At every setting an agent fills a gap from its sources in order, and never with the average
- Migration: a project rebuilds its `coentrify.json` check from the spec, which now checks `agency`
- Game Flavors: ready-made strategies per layer of a game, picked by the director, rolled by `roll-flavors.mjs`, or the game's own, starting with how characters are named
- A new law, Rules Broken On Purpose: a game breaks a rule now and then where the break resonates, an easter egg needs no reason, and the Game Design gate weighs the mix
- Every phase gate of a game gets a few check questions, each tied to a law, answered with reasoning: they prepare the director's call, and make it at `autonomous`
- A game names who it is for, by what binds them and how broad or niche they are, in an audience profile that rules flavors out and favors others
- A game's assets are decided in layers, the way a feature is: the style connects every list, a blueprint adds what its type needs, and an asset's traits, picked from a catalog, set the states it must hold. `check-assets.mjs` checks the chain
- `coentrify game` starts a game: it asks for the mode first, `manual`, `assisted`, `guided` or `autonomous`, sets the project up, and runs the phases to a playable build
- The greeting from `npx coentrify` asks the agent to write it out in its own message, as Greet says since 0.2.4
