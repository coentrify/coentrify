# 0.3.0

Autonomy as an opt-in, piloted on games.

- 253 standards in 23 modules: one added and two changed
- Autonomy, a new opt-in module, opens with Creative Agency: `agency` in `coentrify.json` runs from `director`, the default, through `guided` to `autonomous`, where the agent directs and the director is a stakeholder
- At every setting an agent fills a gap from its sources in order, and never with the average
- Migration: a project rebuilds its `coentrify.json` check from the spec, which now checks `agency`
