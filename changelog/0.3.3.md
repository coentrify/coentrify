# 0.3.3

A round of filings from projects at work.

- 261 standards in 23 modules: five changed
- A story or an epic is linked by its id, like a ticket, so archiving it breaks no link
- Work the director wants now still gets its ticket first, and a tool or a page the director uses is a feature, so it reaches the accept list
- The number of agents follows the machine's load and the budget, for every agent: at each landing the conductor adds one while the load stays below the core count, and the landing's main checks print both
- A mistake that happens now and then and is found quickly is expected, and needs no rule. One that comes back and costs gets a rule or a check, and only that is a trigger to file
