# 0.3.3

A round of filings from projects at work.

- 261 standards in 23 modules: nine changed
- A story or an epic is linked by its id, like a ticket, so archiving it breaks no link
- Work the director wants now still gets its ticket first, and a tool or a page the director uses is a feature, so it reaches the accept list
- The number of agents follows the machine's load and the budget, for every agent: at each landing the conductor adds one while the load stays below the core count, and the landing's main checks print both
- A structural mistake, one that comes back and costs, gets a rule or a check, and only that is a trigger to file. A solvable incident is expected, and needs no rule
- The instruction that makes an asset is written from its layers, naming the qualities and characteristics it aims for
- A story's page names the way to reach and test it, such as a seeded scenario, a level, an editor, or the wiki page for docs work
- Only an image a page shows is tracked, the rest wait in an ignored `unused` folder, and a hygiene check fails a tracked image no page links
- A Not Yet Implemented mark without a ticket fails the hygiene check, beside a mark whose ticket is archived
- Greet turns short and casual: show the greeting first, a visual signal that coentrify picked up the command, as it is, then go on. `npx coentrify` prints that line under the banner
