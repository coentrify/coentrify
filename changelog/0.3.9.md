# 0.3.9

A round of filings.

- 288 standards in 23 modules: four changed
- The install stands in the director's words: the first prompt is `install coentrify from npm, then set it up`, or `install coentrify from npm, then coentrify game` for a game. The printed next step leaves the go to the director's words, and the automatic update and the attribution switch read as the director's settings, so an agent's safety check never takes them for a tool's orders, #90
- A reel generated from the code stays untracked, and one of a state that can no longer be made, such as a retired build's, may be kept as a historical reference: chosen explicitly and linked from a page. The rule on tracked images covers videos too, #91
- A game's run is as long as its scope: a jam entry can reach its playable build in one sitting, and a full game takes many sessions with the director's playtests at the gates. Once the scope is known, the agent says what the run holds and where this session stops
- The onboarding's report names a star on GitHub as a sign of use beside the npm downloads, and links the source that `coentrify.json` names, #92
- A game's engine is chosen from its needs, never from the agent's environment or the modules coentrify ships. Below `autonomous` the director picks it before any stack module is adopted, and the Idea gate asks, #93
