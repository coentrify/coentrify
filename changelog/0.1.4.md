# 0.1.4

Game Design Patterns, a home for the named patterns a game can use, starting with the No-Gear level. Nothing changes in a project's setup.

- 206 standards in 21 modules: one added
- Game Design Patterns names the patterns a game uses where they fit. The first is the No-Gear level: the gear is taken away for a while, the loop is played again from nothing, and the gear comes back
