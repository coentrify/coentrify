# 0.0.6

Healing is a choice in the onboarding, and the tools are generic. Nothing in it is stable yet.

- 196 standards in 21 modules: four changed
- Healing is automatic by default: a subagent strengthens the harness outside the task, and the report names the change for a veto. A project can choose to have the change filed for the director's review instead
- A contributor chooses whether an issue for coentrify waits for the director, or is filed on its own
- The landing scripts run in bash and take their checks as npm scripts, and the wrap-up hook is a spec with an example
