# 0.2.3

The roadmap items an agent can do on its own: the advanced release workflow for a product that is live, a list per asset type, and the update and unlink scripts in Node.

- 252 standards in 22 modules: two added and one changed
- The update and unlink scripts run with Node, so a project needs no Python: `node node_modules/coentrify/src/tools/scripts/coentrify-update.mjs`, and `unlink-missing-standards.mjs` beside it
- Migration: a project that calls `coentrify-update.py` or `unlink-missing-standards.py` by name, in a hook, a script or its own docs, calls the `.mjs` with `node` instead
