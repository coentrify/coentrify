# 0.2.3

The roadmap items an agent can do on its own: the advanced release workflow for a product that is live, a list per asset type, the update and unlink scripts in Node, and the Proof page as one table.

- 252 standards in 22 modules: two added and one changed
- The Advanced Release Workflow, for a product that is live: stories land on `develop`, a release branch is accepted, and main holds only what is live
- A game keeps a list per asset type in its docs: the blueprint first, then an entry per asset, with fields per type, decor among them
- The update and unlink scripts run with Node, so a project needs no Python: `node node_modules/coentrify/src/tools/scripts/coentrify-update.mjs`, and `unlink-missing-standards.mjs` beside it
- Migration: a project that calls `coentrify-update.py` or `unlink-missing-standards.py` by name, in a hook, a script or its own docs, calls the `.mjs` with `node` instead
- The Proof page is one table: per standard, the trap, each model without the rule and with it, and the ruling
