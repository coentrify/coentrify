# 0.3.2

Memory reconsolidation joins the findings, and ARC's Repeat gets its twist.

- 261 standards in 23 modules: one added and three changed
- Memory Reconsolidation: a recall reopens a memory when what happens differs a little from what was expected, and it is stored again, stronger, after Karim Nader's work
- Naming gains Personal Circle Names, first names from the maker's own life, and Named By Type takes the place of Numbered Clones
- Migration: a game that picked Numbered Clones picks Named By Type
- ARC's Repeat comes in a slightly changed situation, recognizably the same action: a small twist cements it, and a large one is learned as a new thing
