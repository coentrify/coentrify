# 0.4.1

The phase gates and the rest of the filings from prototyping: a vertical slice, a gate called on its purpose with a sweep of the standards, a push setting, a draft's home, and Away Time.

- 291 standards in 23 modules: one added and fourteen changed
- A new optional phase, Vertical Slice, before Gameplay: one small part of the world that looks, feels and plays the way the game should, for a game whose look is the bigger unknown. Only what it holds is specced, and it stays internal. When Design starts, the agent asks which is the bigger unknown, #118
- An unmet criterion is no departure: before a ticket's Done part is written, or a phase gate passes, each unmet one is listed to the director with one push back, and the close waits for the answer, #119
- A phase gate is called in one message of a fixed shape: the phase's purpose as a reminder, whether it is met, each part left open with one push back, nothing that does not bear on the purpose, and "ready to move on to" the next phase, the director's idea
- A new setting, `push`: with `automatic`, a turn that committed to main ends with main pushed once its records have landed, skipping the pre-push hook, and a tag is pushed by name as it is added. Left out, it follows `agency`: `review` at `manual` and `assisted`, `automatic` at `guided` and `autonomous`. A new Push Check spec holds it at the end of a turn, and the Coentrify JSON Check holds its value, #120
- A draft for coentrify stays in the repository until it is filed: in the tickets workflow under `### Issue For Coentrify` in the Done part of the ticket carrying its change, in the simple workflow in a file beside the lists, linked from the inbox. The decisions link it while it waits, and `issue-link.mjs` reads a ticket's section, #121
- A new layer, Away Time, mixing by scope: what the world does while the game is closed, Frozen World, Capped Catch-Up, Full Catch-Up and World Moves On, #122
- Before a phase gate is called, the agent sweeps the adopted standards for every check, hook, script or generated view they say the project has, and files each gap as debt in the next phase. The phase page holds the sweep under `## Standards Sweep`, and in the tickets workflow a hygiene check fails a passed phase without one, #123
