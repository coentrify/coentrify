# 0.0.7

The commit check knows when a version is tagged. Nothing in it is stable yet.

- 203 standards in 21 modules: three changed
- Once a version is tagged, the commit check refuses a change to a standard until the page of the next version is open
- The commit check refuses an entry for a standard that is back at its released text
- The agent checks generated speech with a transcription tool, and unverified speech can still ship
- The first prompt names the action, the project and the source: `set up coentrify in this project: <link>`
- An update applies each setup change the changelog names, and a version that needs one names the migration in its summary
- A sub-agent for the task at hand needs no go, and never heals on its own: its conductor starts the healing or files it
