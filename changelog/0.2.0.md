# 0.2.0

The first round from a second project, one that already ran an earlier coentrify: the greeting comes first whatever starts the setup, the setup ends with proof from a fresh session, and Contrast holds through time. A project that is set up asks a fresh session which Core Rules it holds, and its wiki slugs headings the way GitHub does, set once in its config.

- 206 standards in 21 modules: three changed
- The greeting is the first message of any setup, as a message of its own, and the package prints it from the onboarding
- The setup ends with proof from a fresh session that names the Core Rules it holds, and an earlier copy is removed only after that proof
- Contrast holds through time as well as in space: an empty or small start sets off a full or large end
- The wiki slugs headings the way GitHub does, so an anchor to a heading with an apostrophe holds in both, and the lint fails an anchor that names no heading
