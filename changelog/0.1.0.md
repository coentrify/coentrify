# 0.1.0

Coentrify ships as an npm package that a project installs as a dev dependency, so an agent reaches the source wherever npm works, a cloud session included. A project from before 0.1.0 sets coentrify up again, the way the onboarding says for an earlier coentrify: it installs the package, names it under `package` in `coentrify.json`, points its entry point at the commands in `node_modules`, and adds the session check.

- 202 standards in 21 modules: none changed
- The package carries the source under `src/`, at coentrify's version, and the release workflow publishes it to npm as its trusted publisher
- `npx coentrify check` starts every session, and says when `coentrify.json` is behind the installed package and what changed in between
- An update raises the package and compares it with the project's version from npm, without a clone of the source
- The Quick Start leads with `npx coentrify`, and keeps the prompt with the source for a machine without Node
