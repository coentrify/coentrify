# 0.4.0

A round of filings from prototyping a game on a dev machine.

- 290 standards in 23 modules: five changed
- Building A Ticket says a commit takes its ticket's id as its scope, as Commits has since 0.3.1, #110
- An update names a new standard that a replaced tracked standard now links to as required, and adopts it at once, never only suggests it. A project with any dated record that 0.3.13 left without The DEV Day adopts it now, `--adopt records/the-dev-day`, #111
- The Conductor runs a coentrify update and its adoption itself, in the main session, so the director follows each step, and hands it to an agent only while builders are at work, #112
- At every agency setting, a detail, such as a name, a line or a number, is no question: it takes the agent's recommendation under Veto, #113
- The main checks script records each check that passed on a clean tree, and the merge script names the checks that passed on the tree it lands, so the conductor reruns only the rest after a landing. A project rebuilds both scripts from the Landing spec, #114
