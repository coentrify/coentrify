# 0.3.6

The gameplay side of our creative sweep.

- 286 standards in 23 modules: seven added and twenty changed
- A new layer, World Structure, mixing by scope: Linear, Hub And Spokes, Interconnected, Open, Arenas, Generated Once and Generated Each Run
- A new layer, Power, mixing by scope: Skill Only, Stats, Gear, Abilities, Allies, Empire and Meta Progression
- A flavor's cost is no verdict: many loved games pick a flavor for its gain, and live with its cost or soften it
- No Try Hard holds for a game made for every type of player, never a competitive one
- A new layer, Difficulty, mixing by scope: Fixed, Chosen, Adaptive, Assist Options and Opt-In Challenge
- A new layer, Time, mixing by scope: Real Time, Turn Based, Pausable Real Time, The Clock, Bendable Time and Real World Time
- A new layer, Art Style, which the style in Asset Layers starts from: Pixel Art, Low Poly, Simple Stylized, Hand Drawn, Cel Shaded, Painterly, Realistic, Voxel and Crafted Materials
- A new layer, Music, mixing by scope: Adaptive Score, Area Themes, Leitmotifs, Sparse, Diegetic Only, Player's Choice and Rhythm
- A new layer, Together, mixing by scope: Solo, Co-op, Competitive, Asymmetric, Same Couch, Shared World and Asynchronous Traces
- A new pattern, The Fall: the player loses what they built and rebuilds it, quicker and cheaper, never a do-over punishment. Chosen, it is prestige or new game plus. Game Design Patterns counts as a hub
- A new pattern, Kishōtenketsu Level: one idea per level, introduced, developed, twisted and concluded
- A new pattern, Juice: generous feedback across the senses for every action, in harmony with the tone, never a circus and never slowing the action
- A new pattern, Coyote Time And Input Buffer: invisible windows of forgiveness, and the player can still fail
- A new pattern, Pity Timer: bad luck protection for a random reward, never with real money
- A new pattern, Chekhov's Gun: what is shown with weight pays off later, hiding in plain sight until it ties back in
- A new pattern, Breadcrumbs: small rewards along the path that invite and never command
- A new pattern, The Body Tells The Story: the body changes with what the player meant, never as a side effect
- A prefilled issue link always ends in a letter, a digit or an escape, so a chat that drops trailing punctuation from a bare link keeps the draft whole
- Extract flavors matches each strategy against the catalog and the patterns first: a near match is recorded with how the game differs, only a real gap is filed, and the report names what the sweep confirmed beside what it found new
